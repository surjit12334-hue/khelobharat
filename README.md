## 🌟 Features

### 🏅 Fixture Management
- Create and organize match fixtures effortlessly
- Support for multiple sports and tournament formats
- Drag-and-drop scheduling interface
- Automatic conflict detection

### 📊 Leaderboard & Tables
- Generate dynamic standings and ranking tables
- Real-time updates during live matches
- Customizable scoring rules
- Export tables in multiple formats

### 👥 Athlete Management
- Complete athlete profiles with photos and stats
- Track performance history and achievements
- Manage team rosters and player assignments

### 🧑‍🏫 Coach & Manager Portals
- Dedicated dashboards for coaches and managers
- Team performance analytics
- Communication tools for team coordination
- Training schedule management

### 🎖️ Certificate Generation
- Design beautiful custom certificates
- Multiple professional templates
- Auto-fill athlete details
- Personalized awards and recognitions

### 📧 Email Integration
- Send certificates directly via email
- Bulk email support for entire teams
- Custom email templates
- Delivery tracking and notifications

## 🛠️ Getting Started

### Prerequisites

- **Node.js** (v18 or higher)
- **npm** or **yarn**
- **MongoDB** instance (local or cloud)

### Installation

```bash
# Clone the repository
git clone git@github.com:surjit12334-hue/khelobharat.git

# Navigate to project directory
cd khelobharat

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env

# Start development server
npm run dev
```

### Environment Variables

```env
PORT=3000
MONGODB_URI=your_mongodb_connection_string
EMAIL_SERVICE=your_email_service
EMAIL_API_KEY=your_api_key
JWT_SECRET=your_jwt_secret
```
